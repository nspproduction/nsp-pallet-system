- ระบบ เบิก/คืน พาเลท เพื่อบริหารพาเลทและ monitor
- ฉันจะให้ user ใช้กันผ่าน line liff โดย user ต้องทำการลงทะเบียนก่อน จากนั้น admin ค่อยเข้าไป active ระหว่างที่ status pending/inactive จะไม่สามารถเข้าหน้าใช้งานได้
- ฉันจะให้ user มีข้อมูลพื้นฐานและต้องมีแผนก โดยมีแผนกดังนี้ (สามารถเพิ่มได้)
  - คลังพาเลท
  - ผลิต (มี section ย่อยอีก)
  - พัสดุ
  - จ่ายสินค้า
  - QA
  - RD
- โดยที่ทุกแผนกจะมี role เป็น requester ยกเว้น คลังพาเลท ที่จะเป็นแผนกที่ต้องมีการ approve และ store keeper แสดงว่า user จะมี 4 role ได้แก่ requester, store keeper, approver และ admin โดยที่
  - requester ทำได้แค่ เบิก/คืน
  - approver ทำได้แค่ อนุมัติ
  - store keeper ทำการจัดการภายใน
  - admin จัดการข้อมูล master ผู้ใช้งาน และอื่นๆ
- มี use case ประมาณนี้
  - แผนกผลิต alpha/beta เบิกพาเลทไปวางงาน จากนั้นงานถูกส่งไปพร้อมพาเลทที่ section mixer หลังจาก section mixer ใช้งานเสร็จจะส่งคืนคลังพาเลท
  - แผนผลิต packer เบิกพาเลทไปวางงาน เมื่อวางงานเสร็จ งานและพาเลทจะถูกส่งไปยัง จ่ายสินค้า และจ่ายสินค้า จะมี 2 กรณีคือ ลกค้าใช้พาเลทนั้นไหม ถ้าใช้ก็จะเอาพาเลทนั้นไปกับลูกค้าด้วย และลูกค้าจะเอาพาเลทนั้นมาคืนรอบถัดไป แต่อีกกรณีคือลูกค้าไม่ใช้พาเลท จะมีการเอาพาเลทออกระหว่างโหลดสินค้าและ แผนกจ่ายสินค้าจะส่งคืนคลังพาเลท
  - แผนก rd/qa ต้องการเทสสินค้าเลยไปเบิกพาเลทและเมื่อใช้เสร็จก็คืนพาเลท
  -
- การเบิก จะมีเฉพาะสภาพดี ส่วนการคืน requester สามารถระบุได้ว่า คืนสภาพไหนเท่าไหร่ ได้แก่ ดี, ส่งซ่อม, เสีย โดย approver อาจจะทำการอนุมัติ แต่ store keeper ต้องเช็คว่าของที่เอาเข้า ตรงตามเงื่อนไขที่กรอกมาไหม ถ้าไม่ตรงต้องปรับได้ (แต่ฉันยังนึกไม่ออกว่าจะวางโฟลอย่างไร)
- ระบบสามารถนำเข้าพาเลทได้ โดยจะนำเข้าจาก พัสดุ (ฉันยังไม่แน่ใจว่าจะให้คนเป็น request นำเข้า)
